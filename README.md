
# **Frontend project Co.**
Frontend project for built with **Next.js**,

**frontend** repo

## Prerequisites

- Node.js (LTS recommended)
- One package manager: `npm`, `yarn`, `pnpm`, or `bun`

## Install Dependencies
```bash
npm install
# or
yarn
# or
pnpm install
# or
bun install
```

## Run Development Server
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

### Open your browser and visit:

```text
http://localhost:3000
```

# Build for Production
```bash
npm run build
# or
yarn build
# or
pnpm build
# or
bun run build
```

# Start Production Server (Optional)
```bash
npm start
# or
yarn start
# or
pnpm start
# or
bun start
```
